# Spotify Data Analysis Dashboard 🎵

An interactive Spotify Data Analysis Dashboard built using Microsoft Power BI to analyze music streaming trends, artist performance, track popularity, and listener insights. The dashboard provides meaningful visualizations and analytics to understand user engagement and music trends effectively.

## 🚀 Features

* Spotify Streaming Analysis
* Artist & Track Performance Insights
* Popular Genre Analysis
* Monthly Listening Trends
* Top Songs & Artists Tracking
* Interactive Filters & Slicers
* Dynamic KPI Monitoring
* User-Friendly Visualizations

## 🛠️ Tools & Technologies Used

* Microsoft Power BI
* Power Query
* DAX Functions
* Data Cleaning & Transformation
* Business Intelligence Techniques

## 📂 Project File

* `Spotify Data Analysis.pbix`

## 📊 Dashboard Visualizations

* 📈 Line Charts for Streaming Trends
* 📊 Bar Charts for Top Artists & Songs
* 🍩 Donut Charts for Genre Distribution
* 🎯 KPI Cards for Total Streams, Artists & Tracks
* 📅 Monthly Trend Analysis

## 📈 Key Insights

* Identified most streamed songs and artists
* Analyzed genre-wise popularity
* Tracked listening trends over time
* Compared streaming performance across categories
* Visualized user engagement patterns
